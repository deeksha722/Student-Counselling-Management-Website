# 🎓 Student Counselling Management Website

## 📌 Project Overview

The Student Counselling Management Website is a frontend web development project designed to present student counselling-related information through a structured, responsive, and user-friendly interface.

## 🎯 Objectives

* Design a website interface for student counselling.
* Organize counselling-related information clearly.
* Create a responsive layout for different screen sizes.
* Apply modern web design techniques using HTML, CSS, and Bootstrap.

## 🛠️ Technologies Used

* **HTML5** – Structures the webpage content.
* **CSS3** – Adds styling and visual design.
* **Bootstrap** – Provides responsive layouts and reusable UI components.

## ✨ Features

* Student counselling website interface.
* Responsive webpage layout.
* Structured content presentation.
* Bootstrap-based styling and components.
* User-friendly navigation and design.

## 📂 Project Structure

```text
Student-Counselling-Management/

```

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Explore the website interface.
